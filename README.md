# Power BI Portfolio Demonstrations

Three end-to-end portfolio case studies for operations analytics. **Every record is synthetic** and no employer or customer data is used.

## Projects
1. Warehouse Service & Pick Productivity: 240 fictional orders, OTIF proxy, picking and dock wait.
2. Inventory Health & Replenishment Risk: 720 fictional monthly SKU-site snapshots, reorder gaps and aging.
3. Carrier & Route Reliability: 300 fictional trips, on-time performance, exceptions, fuel, and cost.

Each project contains CSV data, a Power Query M loader, DAX measures, a README/modeling notes, and a self-contained HTML dashboard concept. Import the CSV into Power BI Desktop, paste the M query after updating the file path, and add the measures from the DAX file. The HTML previews are concepts, not Power BI reports.
